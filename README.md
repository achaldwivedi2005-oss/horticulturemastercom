# Horticulturemastercom

Build a premium, modern, fully responsive educational website called "Horticulture Master" for Indian agriculture and horticulture competitive exam aspirants.



BRAND:

Horticulture Master

Tagline: CUET-PG | ICAR JRF | ICAR SRF | ASRB NET | Competitive Exams



DESIGN:

Create a beautiful, professional EdTech website with smooth animations, modern typography, attractive gradients, interactive cards, subtle hover effects, scroll animations, and a clean layout. Use a professional green and white color palette inspired by horticulture and agriculture. Ensure excellent mobile and desktop responsiveness.



PAGES AND FEATURES:



1. Home Page:



- Premium animated hero section.

- Welcome message and Start Learning button.

- Exam categories for CUET-PG, ICAR JRF, ICAR SRF and ASRB NET.

- Featured quizzes, latest notifications, popular study materials and recent job updates.

- Statistics cards for quizzes, questions and students, without inventing real numbers.

- Links to Telegram, WhatsApp and YouTube.



2. Online Quiz Portal:



- Subject-wise MCQ tests.

- Vegetable Science, Fruit Science, Floriculture and other horticulture subjects.

- Configurable question timer.

- Configurable positive and negative marking.

- Automatic scoring and answer explanations.

- Results and leaderboard.

- Test history and performance analytics.



3. Study Materials:



- Organised notes and PDF library.

- Subject-wise and topic-wise categories.

- Search and filtering.

- Admin-managed downloadable resources.



4. Agriculture Jobs Portal:



- Government agriculture and horticulture jobs.

- ICAR and agricultural university vacancies.

- Eligibility, vacancies, deadlines and official notification links.

- Search and filter options.



5. Student Dashboard:



- Secure registration and login.

- Quiz history, scores, accuracy and bookmarked questions.

- Responsive and user-friendly interface.



6. Admin Dashboard:



- Manage questions, quizzes, notes, job posts and announcements.

- Edit answers and explanations.

- Manage published content without editing code.



7. Additional Features:



- SEO-friendly page structure.

- Fast loading and accessible design.

- Dark mode toggle.

- Contact page and About page.

- Reusable components and clean code.



IMPORTANT:

Build a functional website, not just a static visual mockup. Use a suitable database and secure authentication for student accounts. Do not fabricate quiz results, student counts, job vacancies or other statistics. Clearly distinguish implemented features from placeholders. Start by building the homepage and shared design system, then implement the remaining sections in stages.
